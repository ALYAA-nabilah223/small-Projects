# Rock Paper Scissor

## Description
> A simple console program to play traditional rock paper scissor involving 2 players.

## Features
- There are 2 modes available
  - Single
  - Multiplayer
- On every match, the player can choose how many rounds they wanted to compete
- There are three choices for player to choose:
  - Rock
  - Paper
  - Scissor
- Each player will simultaneously input their choices
- The winner of the round will be chosen based on the result according to the rule of the game
- Depend on the number of round, the overall winner will be the one who won the most
